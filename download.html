Download Software

Get started with Auxora Nanolabs by downloading our control software and following our step-by-step installation guide.

System Requirements

Before installation, ensure you have:

  • Operating System: Windows 10 or later, macOS, or Linux
  • Python: Version 3.10 or later installed
  • Internet Access: Required for downloading dependencies
  • USB Port: If connecting to hardware

Check Your Python Version

Open Command Prompt (Windows) or Terminal (macOS/Linux) and type:

python --version

If Python is not installed, download it from:

https://www.python.org/downloads/

Downloading the Software from GitHub

If Git is installed:

  1. Open Command Prompt or Terminal
  2. Navigate to the folder where you want the project saved:
    3. cd Desktop
  3. Run the following command:
    4. git clone https://github.com/Blingblingboy16/NEWGUI.git
  4. Press Enter. The project folder will download automatically.

If Git is not installed:

Download Git from:

https://git-scm.com/

Installing Required Python Libraries

After downloading the project, before running the software, create and activate a virtual environment.

Step 1: Navigate to the Project Folder

Open Command Prompt (Windows) or Terminal (macOS/Linux) and navigate to the project directory:

cd auxora-nanolabs

Step 2: Create a Virtual Environment

Run the following command:

python -m venv venv

This will create a virtual environment folder named venv inside the project directory.

Step 3: Activate the Virtual Environment

On Windows:

venv\Scripts\activate

On macOS/Linux:

source venv/bin/activate

Once activated, your terminal prompt will show (venv) at the beginning of the line. The software is now ready to run within the virtual environment.

Running the Software

To start the program:

  1. Ensure you are inside the project directory
  2. Run:
    3. python new.gui.py

Connecting to Hardware

Before launching the software:

  • Connect the Auxora Nanolabs hardware via USB
  • Verify the correct COM port is selected in the software
  • Ensure drivers are installed (if applicable)
